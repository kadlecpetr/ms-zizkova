Editor webu

Klikněte na kterýkoli text na stránce a přepište ho. Fotky vyměníte kliknutím na ně. Aktuality se spravují v pravém panelu. Až budete hotová, stiskněte Publikovat.

Kde vezmu přístupový klíč?
  1. Správce webu (účet vlastnící repozitář kadlecpetr/ms-zizkova) otevře GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Vybere pouze repozitář ms-zizkova a oprávnění Contents: Read and write (volitelně Actions: Read-only kvůli zobrazení průběhu publikace).
  3. Vygenerovaný klíč pošle paní ředitelce. Uloží se jen v jejím prohlížeči a lze ho kdykoli zrušit.

Jak upravovat

  • Text: klikněte do něj a pište. Označený text můžete zvýraznit nebo udělat odkaz.
  • Fotka: klikněte na ni a vyberte novou.
  • Aktuality: záložka nahoře.
  • Texty se stejným zněním (např. v patičce) se mění na všech stránkách najednou.
